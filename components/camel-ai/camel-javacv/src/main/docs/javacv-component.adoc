The JavaCV component provides the capability to capture video frames from various sources
(cameras, video files, network streams) using JavaCV's FrameGrabber implementations.

Maven users will need to add the following dependency to their `pom.xml` for this component:

[source,xml]
----
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-javacv</artifactId>
    <version>x.x.x</version>
</dependency>
----

== URI format

[source]
----
javacv:source[?options]
----

Where *source* can be:

* A device number (e.g., `0` for the default webcam)
* A file path (e.g., `/path/to/video.mp4`)
* A URL (e.g., `rtsp://camera/stream`)

== FrameGrabber Types

The component supports different FrameGrabber implementations:

[width="100%",cols="1,3",options="header"]
|===
| Type | Description
| FFMPEG | Default. Uses FFmpeg libraries. Best for files, streams, and most use cases.
| OPENCV | Uses OpenCV VideoCapture. Good for webcams and simple captures.
| IPCAMERA | For IP cameras via HTTP/MJPEG streams.
| VIDEOINPUT | Windows-only Video Input library.
| DC1394 | IEEE 1394 (FireWire) cameras.
| FLYCAPTURE2 | Point Grey FlyCapture2 SDK cameras.
| OPENKINECT | Microsoft Kinect v1.
| OPENKINECT2 | Microsoft Kinect v2.
| REALSENSE | Intel RealSense (original).
| REALSENSE2 | Intel RealSense D4xx series.
| PS3EYE | PlayStation 3 Eye camera.
|===

== Usage Examples

=== Capture from webcam

[source,java]
----
from("javacv:0?grabberType=OPENCV")
    .process(exchange -> {
        Frame frame = exchange.getIn().getBody(Frame.class);
        // Process the frame
    });
----

=== Capture from video file

[source,java]
----
from("javacv:/path/to/video.mp4")
    .to("direct:processFrame");
----

=== Capture from RTSP stream

[source,java]
----
from("javacv:rtsp://camera/stream?imageWidth=1920&imageHeight=1080")
    .to("direct:processFrame");
----

== Message Headers

The component sets the following headers on each exchange:

[width="100%",cols="1,1,3",options="header"]
|===
| Header | Type | Description
| CamelJavaCVFrameTimestamp | long | Frame timestamp in microseconds
| CamelJavaCVFrameNumber | long | Sequential frame counter
| CamelJavaCVKeyFrame | boolean | Whether this is a key frame
| CamelJavaCVWidth | int | Image width in pixels
| CamelJavaCVHeight | int | Image height in pixels
|===

== Message Body

The message body contains an `org.bytedeco.javacv.Frame` object which provides access to:

* Image data via `image` buffer array
* Audio data via `samples` buffer array (if present)
* Metadata like timestamp, dimensions, and frame type
